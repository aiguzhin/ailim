# План расширения уроков и заданий

Цель: по 3 урока и 3 задания в каждом из 10 направлений, от новичка к среднему уровню. Сейчас 11 уроков и 12 заданий.

## Правила для новых материалов

- Каждый урок: цель, короткое объяснение, 3–5 шагов с примером запроса, практическое задание, итог, время чтения (`minutes`) и время задания (`taskMinutes`).
- Каждое задание с выбором ответа объясняет **каждый** вариант (`why`). У заданий «свой запрос» есть чек-лист, подсказка и пример.
- Материал появляется сразу на трёх языках с одинаковыми `id` (проверка: `npm run check`).
- Русский текст — исходный. Английский и казахский переводит человек или ИИ, после чего их читает носитель языка. Пока казахский перевод не проверен, на сайте показывается пометка «Қазақша аударманы әзірге тілші-редактор тексерген жоқ». Её отключают, когда редактор подтвердит перевод (пустая строка в ключе `i18n.unreviewed` файла `kk.json`).
- Не выдумывать возможности конкретных сервисов: уроки учат приёмам, которые работают в любом чат-боте.
- Обучение остаётся открытым без регистрации.

## Улучшения практики

- Задания «свой запрос»: к чек-листу добавить мягкие автоматические подсказки, например «не указан объём», если в тексте нет чисел. Без оценки «правильно/неправильно» и без отправки текста на сервер.
- Повторение: через неделю после урока предлагать 1 задание из того же направления (только для вошедших пользователей, по настройке напоминаний).

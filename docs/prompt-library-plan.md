# Библиотека промптов Ailim: структура на согласование

Статус: **черновик для согласования**. Код и сайт пока не менялись.

## 1. Объём

| | Минимум по заданию | Предлагаю |
|---|---|---|
| Категории | 20 | **30** (все из задания) |
| Подтемы | 10 в категории | **10–12** в категории, всего **330** |
| Промпты | 4 на подтему | **4** на подтему (короткий, подробный, улучшение, самопроверка), всего **1320** |
| Языки | ru, kk, en | ru — исходный; en и kk переводятся пакетами вместе с русским |

Итого около 4000 текстов промптов на трёх языках. Всё это делается через данные: новая тема или промпт добавляется строкой в JSON, страницы копировать не нужно.

## 2. Как промпты привязаны к инструментам

Инструментам не назначается одинаковый набор тем. У каждого инструмента есть **профиль возможностей**, проверенный по официальной документации, а у каждой подтемы — **нужная возможность**. Сайт сам показывает только те инструменты, у которых она есть.

| Возможность | Код | Кому подходит (после проверки по документации) |
|---|---|---|
| Текстовый диалог | `chat` | ChatGPT, Claude, Gemini, Microsoft Copilot |
| Ответы со ссылками на источники | `sources` | Perplexity; ChatGPT, Gemini и Copilot — если поиск включён в вашем тарифе |
| Работа со своими материалами | `own-docs` | NotebookLM, Claude, ChatGPT (загрузка файлов) |
| Перевод и правка стиля | `translate` | DeepL, Grammarly (только английский) |
| Создание изображений | `image-gen` | Midjourney, Adobe Firefly, Canva, ChatGPT, Gemini |
| Создание и монтаж видео | `video` | Runway, CapCut |
| Озвучка текста | `tts` | ElevenLabs |
| Музыка | `music` | Suno |
| Код в редакторе | `code-ide` | GitHub Copilot, Cursor |
| Презентации и документы | `slides` | Gamma, Canva |
| Заметки и задачи | `notes` | Notion AI |

Если задача инструменту не подходит, карточка предлагает альтернативу. Пример: «Perplexity не создаёт изображения → посмотрите Adobe Firefly или Canva».

## 4. Модель данных

Метаданные хранятся один раз, тексты лежат отдельно по языкам. Каждая категория — отдельный файл, поэтому страница загружает только то, что открыто.

```
public/content/prompts/index.json         категории и подтемы (id, иконка, возможность, связанный урок)
public/content/prompts/<категория>.json   метаданные промптов категории
public/content/<язык>/prompts/<категория>.json   тексты на языке
public/content/tool-profiles.json         возможности инструментов + источник + дата проверки
```

Метаданные одного промпта:

```json
{
  "id": "study.explain.detailed",
  "subtopic": "study.explain",
  "kind": "detailed",               // short | detailed | refine | check
  "level": 2,                        // 1 новичок · 2 средний · 3 продвинутый
  "result": "explanation",           // explanation | list | table | plan | text | quiz | image | video | audio | code
  "needs": ["chat"],                 // нужная возможность → подходящие инструменты
  "audiences": ["school", "students"],
  "placeholders": ["тема", "уровень", "объём"],
  "lesson": "study-tutor",           // связь с уроком
  "checked": "2026-11-26"
}
```

Текст на языке:

```json
{
  "study.explain.detailed": {
    "title": "Подробное объяснение темы",
    "task": "Разобраться в новой теме на своём уровне",
    "prompt": "Объясни тему [тема] для [уровень]. ...",
    "verify": "Сверьте 2–3 ключевых факта с учебником."
  }
}
```

Избранное работает как сейчас: в базе появляется тип записи `prompt:<id>`. Схему базы менять не нужно.

## 5. Как это будет выглядеть на сайте

- **/prompts** — обзор: 29 категорий плиткой, поиск по задачам и блок «Мне нужно сделать…». Вы вводите «план доклада» и получаете подходящие подтемы и инструменты.
- **/prompts/<категория>** — подтемы, у каждой четыре промпта: короткий, подробный, улучшение и самопроверка.
- Фильтры: категория, уровень, тип результата, инструмент, аудитория. Есть «Сбросить фильтры» и понятный пустой результат.
- **/prompts?tool=claude** — страница инструмента: что он умеет по документации, какие темы ему подходят, а для каких лучше взять другой инструмент. Из каталога инструментов ведёт кнопка «Промпты для этого инструмента».
- **Карточка промпта:**
  - поля для заполнителей, текст обновляется сразу и только у вас в браузере, никуда не отправляется;
  - кнопки «Скопировать», «Изменить», «В избранное»;
  - блоки «Проверь ответ» и «Будь осторожен с данными»;
  - ссылки на урок и страницу инструмента.
- Если в поле ввести почту или телефон, появится предупреждение (так уже работает в конструкторе).

## 6. Примеры готовых карточек

### А. Текстовый ассистент — Учёба → Объяснить сложную тему (подробный)
- **Инструменты:** ChatGPT, Claude, Gemini, Microsoft Copilot · **Уровень:** новичок · **Результат:** объяснение
- **Задача:** разобраться в теме на своём уровне, а не получить готовый ответ
- **Промпт:**
  > Объясни тему «[тема]» для [уровень: например, ученик 8 класса]. Я уже знаю: [что знаю]. Мне непонятно: [что непонятно]. Начни с простой аналогии, затем дай объяснение в [объём: 5–7] коротких абзацах и один пример из жизни. Если в чём-то не уверен, прямо отметь это. В конце задай мне 3 вопроса для самопроверки, но не показывай ответы.
- **Заменить:** [тема], [уровень], [что знаю], [что непонятно], [объём]
- **Проверь ответ:** сверьте определения и даты с учебником; если аналогия кажется неточной, спросите, где она не работает.
- **Данные:** имя, школа и другие личные сведения не нужны.
- **Урок:** «ИИ как репетитор» · **Проверено:** 26.11.2026

### Б. Поиск с источниками — Проверка фактов → Таблица «утверждение — источник» (подробный)
- **Инструменты:** Perplexity (ответы со ссылками). Если поиск в вашем тарифе включён, подойдут ChatGPT и Gemini · **Уровень:** средний · **Результат:** таблица
- **Промпт:**
  > Проверь утверждения ниже. Для каждого найди 2 независимых источника и оформи таблицу: «утверждение — источник 1 — источник 2 — подтверждено / не подтверждено / спорно». Используй только источники с указанным автором или организацией и датой. Если подтверждения нет, так и напиши, ничего не додумывай. Утверждения: [материал]
- **Заменить:** [материал]
- **Проверь ответ:** откройте каждую ссылку и найдите в ней нужную фразу. ИИ может приписать источнику то, чего там нет.
- **Урок:** «Как проверять ответы ИИ»

### В. Генератор изображений — Создание изображений → Чего не должно быть на изображении (подробный)
- **Инструменты:** Midjourney, Adobe Firefly, Canva · **Уровень:** средний · **Результат:** изображение
- **Особенность:** у генераторов изображений свои поля и параметры. Карточка не придумывает их, а пишет: «если в вашем генераторе есть отдельное поле для исключений, перенесите туда вторую часть».
- **Промпт:**
  > [объект], [действие], [окружение]. Стиль: [стиль]. Ракурс: [ракурс]. Свет: [свет]. Палитра: [палитра]. Без текста и надписей на изображении, без логотипов, без узнаваемых реальных людей.
- **Проверь ответ:** нет ли лишних рук, искажённого текста или случайных логотипов; подходят ли условия сервиса для вашей цели.
- **Осторожно:** не создавайте изображения реальных людей без их согласия.

### Г. Помощник по коду — Программирование → Минимальный пример ошибки (улучшение)
- **Инструменты:** GitHub Copilot, Cursor (в редакторе), а также ChatGPT и Claude · **Уровень:** продвинутый · **Результат:** код
- **Промпт:**
  > Вот фрагмент кода и полный текст ошибки. Помоги сократить код до минимального примера, который воспроизводит ту же ошибку, и объясни, что ты убрал и почему. Ключи и пароли я заменил заполнителями. Код: [материал] Ошибка: [текст ошибки]
- **Проверь ответ:** запустите минимальный пример и убедитесь, что ошибка та же.
- **Осторожно:** перед отправкой замените ключи на `YOUR_API_KEY`.

### Д. Озвучка — Аудио → Текст для чтения вслух (самопроверка)
- **Инструменты:** любой текстовый ассистент для текста, ElevenLabs для озвучки · **Результат:** текст
- **Промпт:**
  > Прочитай мой текст для озвучки и отметь места, где слушатель может потерять мысль: слишком длинные фразы, сокращения, цифры, которые трудно воспринимать на слух. Ничего не переписывай, только перечисли проблемы и предложи, где поставить паузы. Текст: [материал]
- **Осторожно:** чужой голос можно клонировать только с согласия человека.

## 7. Как предлагаю реализовать

1. **Пакет 1.**
   - Движок каталога: страницы, поиск, фильтры, подстановка значений, избранное, «Мне нужно сделать…», профили инструментов с проверкой по официальной документации.

# Ailim: учимся пользоваться ИИ

Образовательный сайт: короткие уроки, каталог ИИ-инструментов, практика, конструктор запросов, личный кабинет с прогрессом. Интерфейс и материалы на русском, английском и казахском языках.

## Что внутри

| Часть | Технология |
|---|---|
| Сервер | Node.js 20+, Express |
| База данных | PostgreSQL (на хостинге Neon) |
| Пароли | scrypt со случайной солью, сравнение за постоянное время |
| Вход | httpOnly cookie, сессии хранятся в базе в виде SHA-256 токена, 30 дней |
| Защита | Helmet (CSP и др.), проверка Origin для изменяющих запросов, SameSite=Lax, ограничение попыток входа |
| Интерфейс | Без фреймворков: ES-модули, свои шрифты (Inter, Inter Tight), без внешних трекеров |

```
server/        API, авторизация, схема БД
public/js/     интерфейс (pages/ — страницы)
public/i18n/   переводы интерфейса (ru, en, kk)
public/content/ уроки, задания, инструменты, опрос — по папке на язык
scripts/       проверка переводов, локальная база для разработки
```

## Запуск локально

```bash
npm install
npm run dev:db          # в отдельном терминале: локальный PostgreSQL на порту 5433
DATABASE_URL=postgres://ailim:ailim@localhost:5433/ailim npm start
```

Откройте http://localhost:3000. Таблицы создаются автоматически при старте.

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `DATABASE_URL` | да | Строка подключения PostgreSQL (Neon → Connection string) |
| `NODE_ENV` | на сервере | `production`: включает secure-cookie |
| `PUBLIC_URL` | желательно | Адрес сайта для ссылок в письмах, например `https://ailim.onrender.com` |
| `RESEND_API_KEY` | для восстановления пароля | Ключ сервиса писем [Resend](https://resend.com) |
| `MAIL_FROM` | вместе с ключом | Отправитель, например `Ailim <no-reply@ваш-домен>` (домен подтверждается в Resend) |
| `SITE_OWNER` | желательно | Кто отвечает за сайт (показывается на странице «Ваши данные») |
| `CONTACT_EMAIL` | желательно | Почта для вопросов о данных (там же) |
| `ISSUES_URL` | нет | Куда сообщать об ошибках. По умолчанию — страница Issues репозитория на GitHub |

Пока ключа для писем нет, страница «Забыли пароль?» честно сообщает, что отправка писем не подключена. При локальном запуске ссылка для сброса пишется в консоль сервера.

## Как добавить язык

1. Добавьте язык в `public/content/languages.json`.
2. Скопируйте `public/i18n/ru.json` в `public/i18n/<код>.json` и переведите значения.
3. Скопируйте папку `public/content/ru` в `public/content/<код>` и переведите тексты, не меняя `id`.
4. Выполните `npm run check`: скрипт покажет пропущенные ключи и несовпадения структуры.

## Как добавить урок или инструмент

- Урок: новый объект в `public/content/*/lessons.json` (во всех языках с одинаковым `id`).
- Инструмент: строка в `public/content/tools.json` и описание в `public/content/*/tools.json`. Обновите дату `updated`.
- Условия инструмента (бесплатный тариф, аккаунт, возраст, Казахстан) лежат в поле `facts` в `public/content/tools.json`. Меняйте их только после проверки на официальной странице: ссылку добавляйте в `sources`, дату — в `checked`. Если сведения не удалось подтвердить, ставьте `unverified`, и сайт так и напишет.
- После изменений выполните `npm run check` и перезапустите сервер.

## Проверено

Регистрация, вход, ошибка неверного пароля, выход, защита закрытых страниц, сохранение шага урока и продолжение после перезагрузки, завершение урока, избранное, задания практики, конструктор и предупреждение о личных данных, опрос и перенос плана гостя в аккаунт, смена языка с сохранением в профиле, тёмная тема, сброс пароля по одноразовой ссылке, удаление аккаунта. Отображение проверено на ширине 390, 820 и 1440 px без горизонтальной прокрутки.
